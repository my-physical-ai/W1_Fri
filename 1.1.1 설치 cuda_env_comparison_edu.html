핵심 구조

계층 관계 완전 정리

🚗
핵심 비유 — 자동차

PyTorch = 운전자 (방향 결정, 무엇을 계산할지)
CUDA = 엔진 (실제 동력, 어떻게 GPU로 처리할지)
드라이버 = 계기판·제어 장치 (엔진 상태 관리, 번역)
GPU = 도로 + 연료 (실제 수학 계산 수행)

💡 "운전자(PyTorch)가 엔진(CUDA) 역할도 하면 되지 않나?" → 완전히 다른 전문 영역입니다. CUDA 없이 PyTorch만으로는 GPU를 제어할 수 없어요.

실제 설치 순서 — CUDA 있는 환경 (Ubuntu 24.04 + RTX GPU)

⚠️
순서가 매우 중요합니다! 드라이버 → CUDA(PyTorch에 포함) → PyTorch 순서로 설치해야 합니다. 순서가 틀리면 버전 충돌이 발생합니다.
  • 1
    NVIDIA 드라이버 설치 — 가장 먼저!
    Ubuntu 소프트웨어 업데이트 → 추가 드라이버 탭 → NVIDIA driver 선택 → 적용
    ubuntu-drivers autoinstall # 자동 설치 (권장) sudo apt install nvidia-driver-535 # 직접 지정 설치 sudo reboot # 재부팅 필수! nvidia-smi # 설치 확인 → GPU 정보 표시되면 성공
  • 2
    Miniforge (Conda) 설치
    Python 환경 분리를 위해 시스템 Python 건드리지 않고 Conda 사용
    wget https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-Linux-x86_64.sh bash Miniforge3-Linux-x86_64.sh
  • 3
    PyTorch CUDA 버전 설치 — CUDA Toolkit이 자동 포함됨
    PyTorch 2.0부터 CUDA Runtime Library가 PyTorch 안에 포함 → 별도 설치 불필요!
    conda create -n lerobot python=3.10 conda activate lerobot # CUDA 12.1 버전 PyTorch 설치 (CUDA Toolkit 포함) pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121 # 설치 확인 python -c "import torch; print(torch.cuda.is_available())" # → True ✅
  • 4
    LeRobot 설치
    pip install lerobot # 또는 개발용 설치 git clone https://github.com/huggingface/lerobot pip install -e ".[feetech]"
  • 5
    최종 확인
    nvidia-smi # GPU 상태 python -c "import torch; print(torch.cuda.get_device_name())" # GPU 이름 python -c "import torch; print(torch.version.cuda)" # CUDA 버전

현장 워크플로우

AI 워크플로우 — 학습(CUDA 서버) → 배포(Pi 5 / NUC)

🏭
핵심 개념 — 분업

학습과 배포는 다른 장비에서 합니다. PC/서버(CUDA)에서 무거운 AI 학습을 하고, 완성된 모델만 Pi 5 / AGX Orin에 올려서 실행합니다. 공장에서 매번 현장 장비로 학습하지 않아요.

✅ Ubuntu 24.04
✅ NVIDIA 드라이버
✅ CUDA 12.x
✅ PyTorch (CUDA 버전)
✅ LeRobot 학습 실행

🍓

✅ Ubuntu 24.04 / Pi OS
❌ NVIDIA 드라이버 불필요
❌ CUDA 불필요

# ─── 학습 서버 (RTX 4090, CUDA 있음) ─── model = MyRobotModel() model = model.to("cuda") # GPU 학습 # 1000번 에피소드 학습 (GPU로 30분) for episode in range(1000): loss = train_step(model, data) torch.save(model.state_dict(), "lekiwi_model.pth") # 모델 저장 # ─── Pi 5 현장 (CUDA 없음) ─── model = MyRobotModel() model.load_state_dict( torch.load("lekiwi_model.pth", map_location="cpu") ← CPU로 로드! ) model.eval() # 카메라 영상으로 실시간 추론 (CPU로 충분) while True: frame = camera.read() action = model(frame) # CPU 추론 → 충분히 빠름 lekiwi.move(action) # 르키위 모터 제어

🎯 하드웨어별 설정 핵심 7줄 요약

① RTX 4090 · 4070 · 3080: NVIDIA 드라이버 → PyTorch CUDA 버전 → AI 학습 — 3단계 필수
② AGX Orin: JetPack 설치로 드라이버+CUDA 한번에 해결 — 현장 엣지 AI에 최적
③ Raspberry Pi 5: pip install torch만으로 끝 — CUDA · 드라이버 설정 전혀 불필요
④ Intel NUC: Pi 5와 동일 — CPU 전용 PyTorch만 설치
⑤ 핵심 구분법: nvidia-smi 동작하면 CUDA 환경 / 오류나면 비CUDA 환경 (오류가 정상!)
⑥ 워크플로우: PC(CUDA)에서 학습 → model.pth 파일 → Pi5/Orin에서 실행
⑦ 재직자 교육: CUDA 환경(PC)에서 학습 원리 이해 → 비CUDA 환경(Pi5)에서 현장 배포 실습
