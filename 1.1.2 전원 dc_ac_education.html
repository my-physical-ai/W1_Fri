Section 02

DC와 AC의 진짜 차이

⚡ DC (직류)

전류 방향 — 항상 동일
+ → → → → → →

전기가 항상 같은 방향으로만 흐릅니다

사용 예: 배터리, 건전지, USB, 컴퓨터, 로봇

〜 AC (교류)

전류 방향 — 계속 바뀜
+ → ← → ← → ←

전기가 앞뒤로 왔다 갔다 합니다

한국 가정 콘센트: 220V AC, 초당 60번 방향 변환(60Hz)

🪣 물로 이해하는 DC vs AC
종류물 비유특징
DC 펌프 → 물이 계속 같은 방향으로 흐름 방향 일정, 안정적
AC 물이 앞뒤로 진동 (왕복 흔들림) 방향 변화, 원거리 전송 유리
Section 03

로봇·컴퓨터는 왜 DC를 사용할까?

① 전자회로는 전압 방향이 필요하다

트랜지스터·CPU·IC는 전압 차이로 동작합니다.

0V = OFF   |   5V = ON
AC의 경우: +220V → -220V → +220V → -220V...
⚠ 이러면 디지털 회로 동작 불가능
② 배터리는 DC만 만들 수 있다

배터리는 화학 반응(전자 이동)으로 전기를 만듭니다. 자연스럽게 한 방향 전류(DC)가 됩니다.

공식

배터리 = 화학 반응 = 전자 이동 = DC

③ 전자 부품의 구조
부품특징필요 조건
다이오드한 방향만 전류 통과방향 고정
트랜지스터전압으로 ON/OFF 제어안정적 전압
IC / 마이크로칩일정 전압에서만 동작3.3V / 5V 고정
CPU1.2V / 3.3V 필요전압 방향 안정

Section 06

실물 부품 완전 해설

전체 회로 구성
[파란 배터리]
   │ DC 전원 공급
[WAGO 커넥터]
   │
  ├─ [DC Barrel Jack]
  │   └ 12V 장치 직결
  └─ [DC-DC 컨버터]
        └─ [USB-C 케이블]
             └ 5V 장치 공급
  • 🔵 리튬 배터리
    DC 전원 공급원. 화학 반응으로 한 방향 전류(DC) 생성. 보통 12V 또는 24V 출력.
  • 🔌 WAGO 커넥터 (투명)
    전선을 여러 곳으로 나누는 분배기. 배터리 1개 → 여러 장치로 전원 분배.
  • ⬛ DC-DC 컨버터 (검은 박스)
    Input: DC 12V/24V → Output: 5V 5A (USB Type-C). 배터리 전압을 USB 전압으로 낮춰줌.
  • 🔴 DC Barrel Jack
    12V 직접 연결 커넥터. 라이다·카메라·센서 등 DC 12V 장치에 직결.
  • 🔗 USB-C 케이블
    5V 출력. 라즈베리파이·Jetson·스마트폰·미니PC 등에 전원 공급.

왜 두 선이 필요한가?

전기는 왕복 구조여야 흐릅니다. 물이 나갔다가 돌아오듯, 전기도 + 선으로 나가고 − 선으로 돌아옵니다. 이 회로(Loop)가 끊어지면 전기가 흐르지 않습니다.

DC 소켓(Barrel Jack) 구조
+
바깥 금속 = −
가운데 핀 = + (플러스)
바깥 금속 = − (마이너스)
⚠ + − 반대로 꽂으면 장치 고장·파손
그래서 색상 규칙이 중요합니다
