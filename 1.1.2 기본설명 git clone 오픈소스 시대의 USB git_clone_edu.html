초등학생도 이해하는 비유

🎮
마인크래프트 월드 복사 비유

친구가 만든 멋진 마인크래프트 월드가 서버에 올라가 있어요.
그걸 ① 인터넷에서 → ② 내 컴퓨터로 → ③ 그대로 복사하면,
내 컴퓨터에서도 실행하고 수정할 수 있죠.

💡 이게 바로 git clone입니다. 차이가 있다면, 친구가 월드를 업데이트해도 git pull 한 번이면 내 것도 같이 따라간다는 점이에요.

🏭
공유 창고 ↔ 내 작업실

GitHub = 전 세계 개발자가 공동으로 쓰는 창고
내 컴퓨터 = 내 작업실
창고에 있는 부품(=프로젝트)을 내 작업실로 가져와야 비로소 조립하고 수정할 수 있습니다.

그냥 ZIP 다운로드 vs git clone

GitHub에는 "Download ZIP" 버튼이 있어요. 그냥 그걸 누르면 안 되나요? — 안 되는 건 아니지만, 두 가지는 결과물이 완전히 다릅니다.

📥

ZIP 다운로드

방식 단순 파일 복사
최신 업데이트 ❌ 매번 다시 받기
버전 히스토리 ❌ 없음
이전 버전 복구 ❌ 불가능
팀 협업 ❌ 어려움
크기 .git 폴더 없음 (가벼움)
🌐

git clone

방식 복사 + 원격 연결
최신 업데이트 ✅ git pull 한 줄
버전 히스토리 ✅ 전체 기록 보존
이전 버전 복구 ✅ checkout 한 번
팀 협업 ✅ 표준 방식
크기 .git 포함 (조금 큼)
💡
실전 결론: 단순히 코드 한 번 구경만 할 거면 ZIP도 OK. 하지만 실제로 개발하거나 LeRobot처럼 빠르게 바뀌는 프로젝트를 쓴다면 반드시 git clone으로 받아야 업데이트와 버전 관리가 가능합니다.
5

Clone 이후의 흐름 — 4단계 표준 절차

git clone은 끝이 아니라 시작이에요. 받은 다음에 보통 이 순서로 진행합니다.

Step 1
받기
git clone <URL>
GitHub에서 프로젝트 통째로 가져오기
Step 2
들어가기
cd lerobot
프로젝트 폴더 안으로 이동
Step 3
설치하기
pip install -e .
필요한 파이썬 패키지 설치
Step 4
실행하기
python examples/...
예제 코드 돌려보기

실전 예시: LeRobot 처음부터 끝까지

# 1. GitHub에서 LeRobot 받기 (base) zeta@zeta-MS-7E12:~$ git clone https://github.com/huggingface/lerobot.git # 2. 프로젝트 폴더로 이동 (base) zeta@zeta-MS-7E12:~$ cd lerobot (base) zeta@zeta-MS-7E12:~/lerobot$ # 3. conda 환경 활성화 후 패키지 설치 (base) zeta@zeta-MS-7E12:~/lerobot$ conda activate lerobot (lerobot) zeta@zeta-MS-7E12:~/lerobot$ pip install -e . # 4. 실행 (lerobot) zeta@zeta-MS-7E12:~/lerobot$ python examples/1_load_lerobot_dataset.py ✓ 데이터셋 로드 성공!
💡
pip install -e .의 -e는 "editable" 모드예요. 설치 후에도 lerobot 폴더의 코드를 수정하면 즉시 반영됩니다. 오픈소스 수정/실험할 때 필수 옵션입니다.
6

Clone의 진짜 핵심 — 단순 복사가 아니다

여기까지만 보면 "그냥 폴더 복사 아냐?" 싶을 수 있어요.
하지만 clone은 단순 복사가 아닙니다. 실제로는 훨씬 강력한 일이 일어납니다.

🎯 git clone이 실제로 가져오는 것
파일 + 프로젝트의 역사 전체 + 원격 연결
📂
현재 파일들
📜
모든 변경 기록 (커밋 히스토리)
🌿
모든 브랜치 정보
🔗
원격 저장소 연결 (origin)

그래서 가능해지는 것

한 줄 명령어
하는 일
git pull
최신 코드로 업데이트 — 원격 저장소에서 변경분만 가져옴
git log
프로젝트 변경 역사 보기 — 누가 언제 무엇을 바꿨는지 전부
git checkout v1.0
특정 시점으로 되돌리기 — 옛 버전이 잘 돌아갔다면 그때로 점프
git diff
내가 수정한 부분 보기 — 원본과 무엇이 달라졌는지 비교
🎓 git clone은 폴더 복사가 아니라,
"프로젝트의 살아있는 타임머신을 통째로 내 컴퓨터에 설치"하는 것입니다.
7

평생 쓰는 Git 명령어 5개

피지컬 AI 개발하면서 가장 많이 만나는 5개. 이것만 외워도 90% 해결됩니다.

git clone <URL>
원격 저장소를 내 컴퓨터로 통째로 받기 (가장 자주)
git pull
받아둔 프로젝트 최신 버전으로 동기화 (변경분만 받음)
git status
내가 뭘 수정했는지, 어떤 파일이 추가/삭제됐는지 확인
git log --oneline
프로젝트 커밋 히스토리를 한 줄씩 간단히 보기
git checkout <브랜치>
다른 브랜치나 특정 버전으로 이동 (안전한 실험용 분기)
🎯
꿀팁: 새 프로젝트를 받았다면 가장 먼저 README.md를 열어보세요. 설치법, 실행법, 의존성이 거기 다 적혀있어요. README는 개발자의 설명서입니다.
