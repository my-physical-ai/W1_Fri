1.py 파일은 "도구 상자"

라이브러리도, 옆에 있는 파일도 전부 똑같은 .py 파일이에요.

🧰
옆 사람 도구 상자에서 빌려오기!
.py 파일은 도구 상자, 안의 함수는 도구예요. import는 "옆 사람 도구 상자에서 드라이버 빌려올게!"라는 뜻입니다.
💡 실제로는 — import time도 Python 설치 폴더의 time.py에서 함수를 가져오는 거예요.
1

도구 상자 파일 만들기

왜? 함수를 담아둘 "도구 상자"가 먼저 있어야 빌려 쓸 수 있어요.

📄 calculator.py
# calculator.py — 계산 도구가 들어있는 파일
def add(a, b):
    return a + b

def multiply(a, b):
    return a * b
2

도구 빌려 쓰는 파일 만들기

왜? 같은 폴더의 calculator.py에서 함수를 가져오는 연습이에요.

📄 main.py (calculator.py와 같은 폴더)
# main.py — calculator.py의 도구를 빌려 씁니다
from calculator import add, multiply

result = add(3, 5)         # → 8
result2 = multiply(4, 6)   # → 24
print(result, result2)
3

실행해 보기

왜? import가 진짜 되는지 눈으로 확인해요.

💻 NUC 터미널
python main.py
✅ 이렇게 나오면 성공: 8 24
✅ 핵심라이브러리든 옆 파일이든 원리는 100% 같아요. import = "그 파일의 코드를 여기서 쓰겠다".

2점(.)의 비밀과 -m

from .config_lekiwi import …의 점(.)은 "우리 집에 있는"이라는 뜻이에요.

🏠
아파트 한 집에 사는 가족
lekiwi/ 폴더는 아파트 한 집, 안의 .py 파일들은 같은 집 가족이에요. 점(.)은 "우리 집에 사는"이라는 뜻!
📄 lekiwi_host.py 안의 한 줄
from .config_lekiwi import LeKiwiConfig, LeKiwiHostConfig
#    ↑ 점(.) = "우리 집(같은 폴더)에 있는"
실행 방법Python의 반응결과
python lekiwi_host.py"점(.)? 너 집이 어딘데?"💥 에러
python -m lerobot.robots.lekiwi.lekiwi_host"lekiwi 폴더에 사는 애구나!"✅ 성공
💡 -m 은 "주소 등록"Python에게 "이 파일은 lerobot → robots → lekiwi 집에 살아"라고 알려줘야 점(.)이 어디인지 알 수 있어요.

6최종 점검

아래를 모두 체크하면 실습 2-2 완료!

  • 💻 NUC ~/team1 에 teleoperate_base_keyboard.py 가 있고 remote_ip가 내 팀 IP다
  • 🍓 파이 ~/team1 에 check_wheels.py, identify_wheels.py 가 있다
  • 두 기기 모두 ~/Downloads/teleop/ 에서 복사했다 (다른 폴더 안 만듦)
