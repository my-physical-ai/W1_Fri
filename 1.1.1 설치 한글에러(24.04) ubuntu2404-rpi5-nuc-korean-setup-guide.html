Raspberry Pi Imager 다운로드 & 이미지 굽기

SD카드에 우분투를 넣어줘요

Raspberry Pi Imager는 SD카드에 운영체제를 쉽게 설치해주는 공식 도구예요. 마치 USB에 파일을 복사하는 것처럼 간단해요!

📌 다운로드: raspberrypi.com/software 에서 본인 OS에 맞는 버전을 다운로드하세요.

Imager에서 이미지 굽는 순서:

① 운영체제 선택 클릭 → Other general-purpose OS → Ubuntu → Ubuntu Desktop 24.04 LTS (64-bit) 선택

② 저장소 선택 클릭 → 삽입한 microSD 카드 선택

③ 설정(⚙️) 클릭 → Wi-Fi, 호스트이름, 사용자 계정을 미리 설정 가능

④ 쓰기(WRITE) 클릭 → 완료까지 약 5~15분 대기

⚠️ 주의! 쓰기를 하면 SD카드의 기존 데이터가 모두 삭제돼요. 중요한 파일이 있다면 미리 백업하세요!

ISO 파일이 뭐예요?

ISO 파일은 "CD/DVD를 통째로 하나의 파일로 만든 것"이에요. 예전에는 CD로 설치했는데, 지금은 이 파일을 USB에 넣어서 설치해요!

NUC BIOS 설정 & USB 부팅

NUC에게 "USB로 시작해!"라고 알려줘요

① NUC에 USB 삽입 → 전원 켜기

② 부팅 시 F10 키 연타 → Boot Menu 진입

③ 목록에서 USB 장치 선택 → Enter

📌
BIOS 부팅 키 (NUC 모델별):
F10 → Boot Menu (대부분의 NUC)
F2 → BIOS 설정 진입 (부팅 순서 변경할 때)
F12 → 일부 NUC 모델의 Boot Menu
📖

BIOS가 뭐예요?

BIOS는 컴퓨터의 "아침 알람" 같은 거예요. 컴퓨터가 켜지면 "어디서 운영체제를 불러올까?" 결정하는 첫 번째 프로그램이에요. USB를 선택하면 USB 안의 우분투로 시작해요!

현재 로케일 확인하기

컴퓨터가 어떤 언어를 쓰고 있는지 확인해요

터미널을 열고 (Ctrl + Alt + T) 아래 명령어를 입력해요:

터미널
$ locale

# ✅ 이미 한국어면:
LANG=ko_KR.UTF-8

# ❌ 영어면 (변경 필요):
LANG=en_US.UTF-8
2

한국어 언어팩 + 로케일 설정

컴퓨터에 "한국어 사전"을 넣어줘요

터미널
# 패키지 목록 업데이트
$ sudo apt update

# 한국어 언어팩 설치
$ sudo apt install -y language-pack-ko

# 한국어 로케일 생성 (활성화)
$ sudo locale-gen ko_KR.UTF-8

# 시스템 기본 언어를 한국어로 설정
$ sudo update-locale LANG=ko_KR.UTF-8

한글 폰트 설치하기

화면에 한글 "글자 모양"을 넣어줘요

폰트가 없으면 한글이 □□□로 깨져 보여요!

터미널
$ sudo apt install -y fonts-nanum fonts-noto-cjk

# 폰트 캐시 갱신 (새 폰트를 시스템이 바로 인식)
$ fc-cache -fv
폰트 패키지만든 곳특징
fonts-nanum네이버🇰🇷 나눔 글꼴 — 가독성 최고
fonts-noto-cjk구글🌏 한중일 통합 — 범용성 최고

Fcitx 한글 입력기 설치하기

키보드로 한글을 타이핑할 수 있게 해줘요

터미널
# Fcitx 한글 입력기 + 설정 도구 설치
$ sudo apt install -y fcitx-hangul fcitx-bin

# 기본 입력기를 Fcitx로 변경
$ im-config -n fcitx
💡 fcitx-bin을 함께 설치해야 fcitx-configtool(설정 도구)을 사용할 수 있어요! 빠뜨리면 "명령어를 찾을 수 없습니다" 오류가 나요.

환경변수 설정 (가장 중요! ⭐)

모든 프로그램에서 Fcitx가 작동하도록 설정해요

🚨
핵심 주의사항!
~/.bashrc에 넣으면 터미널에서만 적용돼요!
브라우저, VS Code 등 GUI 앱에서도 한글을 쓰려면 반드시 ~/.xsessionrc에 넣어야 해요!
터미널 — ~/.xsessionrc에 환경변수 추가
$ cat << 'EOF' >> ~/.xsessionrc
export GTK_IM_MODULE=fcitx
export QT_IM_MODULE=fcitx
export XMODIFIERS=@im=fcitx
EOF
환경변수역할빠지면?
GTK_IM_MODULEFirefox, 파일관리자 등GTK 앱에서 한글 입력 불가
QT_IM_MODULEVS Code, KDE 앱 등Qt 앱에서 한글 입력 불가
XMODIFIERSX Window 전체브라우저에서 한글 입력 불가!
⚠️

실수하기 쉬운 포인트

XMODIFIERS=@im=fcitx를 빠뜨리는 경우가 가장 많아요! 터미널에서는 한글이 되는데 브라우저에서만 한글이 안 된다면 이 변수가 빠진 거예요.

재부팅 & Fcitx 설정

설정을 적용하고 한글 입력을 추가해요

터미널
$ sudo reboot

재부팅 후 Fcitx 설정에서 한글을 추가해요:

터미널
# Fcitx 설정 도구 열기
$ fcitx-configtool
📌
Fcitx 설정에서 Hangul 추가하기:
1. 하단의 + 버튼 클릭
2. "현재 언어만 표시" 체크 해제
3. 검색창에 Hangul 입력
4. Hangul 선택 후 OK 클릭
5. Ctrl + Space 또는 한/영 키로 한영 전환!
7

설치 확인 ✅

모든 것이 제대로 되었는지 확인해요

터미널 — 전체 확인
# 1. 로케일 확인
$ locale
LANG=ko_KR.UTF-8  ← 이렇게 나오면 OK!

# 2. 한글 폰트 확인
$ fc-list | grep -i nanum
← 나눔 폰트 목록이 나오면 OK!

# 3. 환경변수 확인
$ cat ~/.xsessionrc
export GTK_IM_MODULE=fcitx
export QT_IM_MODULE=fcitx
export XMODIFIERS=@im=fcitx

# 4. 한글 입력 테스트
$ echo "안녕하세요! 한글이 잘 보이나요? 🎉"

⚡ 한글 설정 원라이너 (한 번에 복사-실행)

경험자를 위한 전체 명령어 한 번에 실행 버전이에요!

터미널 — 전체 한 번에 실행
# 한글 설정 전체 (복사해서 한 번에 붙여넣기)
$ sudo apt update && \
  sudo apt install -y language-pack-ko fonts-nanum fonts-noto-cjk fcitx-hangul fcitx-bin && \
  sudo locale-gen ko_KR.UTF-8 && \
  sudo update-locale LANG=ko_KR.UTF-8 && \
  im-config -n fcitx && \
  cat << 'EOF' >> ~/.xsessionrc
export GTK_IM_MODULE=fcitx
export QT_IM_MODULE=fcitx
export XMODIFIERS=@im=fcitx
EOF

# 그 후 재부팅
$ sudo reboot

PART D. 트러블슈팅

😰 자주 발생하는 문제와 해결법

증상원인해결
한글이 □□□로 깨짐 한글 폰트 미설치 sudo apt install fonts-nanum fonts-noto-cjk
터미널에서만 한글 입력 됨, 브라우저 불가 환경변수를 ~/.bashrc에만 넣음 ~/.xsessionrc에 환경변수 3개 넣고 재부팅
XMODIFIERS 누락 환경변수 3개 중 하나 빠짐 export XMODIFIERS=@im=fcitx 추가
fcitx-configtool 명령어 없음 fcitx-bin 미설치 sudo apt install fcitx-bin
Hangul이 검색 안 됨 fcitx-hangul 미설치 sudo apt install --reinstall fcitx-hangul
apt update 시 GPG 키 오류 외부 저장소(ROS2, RealSense 등) 키 만료 해당 저장소 .list 파일 삭제 또는 키 갱신
Fcitx 트레이 아이콘 안 나옴 Fcitx 자동시작 미등록 ~/.xsessionrc에 fcitx-autostart & 추가
