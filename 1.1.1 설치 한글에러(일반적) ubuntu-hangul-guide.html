💡 왜 한글이 깨질까요?

📖

비유로 이해하기

외국인 친구에게 한글 편지를 보냈는데, 그 친구의 집에 한국어 사전이 없다고 상상해보세요. 편지를 받아도 읽을 수가 없겠죠? 우분투도 마찬가지예요! 한글을 읽는 "사전"이 없으면 글자가 □□□나 ????로 깨져 보여요.

한글이 정상적으로 동작하려면 3가지 핵심 요소가 필요해요:

📜

로케일 (Locale)

"컴퓨터야, 나는 한국어를 쓸 거야!"라고 알려주는 규칙이에요

🔤

폰트 (Font)

한글의 글자 모양이에요. 모양이 없으면 화면에 그릴 수 없어요

⌨️

입력기 (Input Method)

키보드로 한글을 타이핑할 수 있게 해주는 도구예요

⚖️ 입력기 비교: IBus vs Fcitx

한글 입력기에는 두 가지가 있어요. 이 교육자료에서는 Fcitx를 사용합니다!

항목 IBus Fcitx ⭐

🛠️ 단계별 설치 가이드

1

현재 로케일(Locale) 확인하기

컴퓨터가 지금 어떤 언어를 쓰고 있는지 확인해요

로케일(Locale)이란 "컴퓨터야, 나는 한국어를 쓸 거야"라고 알려주는 설정이에요. 먼저 터미널을 열어 현재 상태를 확인합시다.

💡 터미널 열기: Ctrl + Alt + T 키를 동시에 눌러요!
터미널 (Terminal)
$ locale

결과 확인 방법:

결과 예시
# ✅ 이렇게 나오면 이미 한국어 설정 완료!
LANG=ko_KR.UTF-8

# ❌ 이렇게 나오면 한국어 설정이 안 된 거예요
LANG=en_US.UTF-8
📌 UTF-8은 전 세계 모든 글자(한글, 일본어, 이모지 등)를 표현할 수 있는 방법이에요. 꼭 UTF-8이어야 해요!
2

한국어 언어팩 설치하기

컴퓨터에 "한국어 사전"을 넣어주는 단계

컴퓨터가 한국어를 이해하려면 한국어 파일 묶음(언어팩)이 필요해요. 마치 외국어 수업을 듣기 전에 교과서를 사는 것과 같아요!

터미널
# 먼저 프로그램 목록을 최신으로 업데이트
$ sudo apt update

# 한국어 언어팩 설치
$ sudo apt install -y language-pack-ko
🎒

쉽게 말하면...

sudo = "관리자 권한으로!"  |  apt install = "설치해줘!"  |  -y = "물어보지 말고 바로 해!"

3

한국어 로케일 생성 & 설정하기

설치한 언어팩을 활성화하고 기본 언어로 지정해요

언어팩을 설치했으면 이제 활성화해야 해요. 사전을 샀으면 책장에 꽂아야 쓸 수 있는 것처럼요!

터미널
# 한국어 로케일 생성 (활성화)
$ sudo locale-gen ko_KR.UTF-8

# 시스템 기본 언어를 한국어로 설정
$ sudo update-locale LANG=ko_KR.UTF-8

📄 설정 파일 확인: /etc/default/locale

위 명령어를 실행하면 아래 파일이 자동으로 수정돼요:

# /etc/default/locale
LANG=ko_KR.UTF-8
💡 LC_ALL까지 설정하고 싶다면 sudo nano /etc/default/locale로 파일을 열어 LC_ALL=ko_KR.UTF-8을 추가해요.
4

한글 폰트 설치하기

화면에 한글 "글자 모양"을 넣어줘요

로케일은 "규칙"이고, 폰트는 "글자 모양"이에요. 규칙을 알아도 글자 모양이 없으면 화면에 표시할 수 없어요!

터미널
$ sudo apt install -y fonts-nanum fonts-noto-cjk
폰트 패키지 만든 곳 특징
fonts-nanum 네이버 🇰🇷 나눔 글꼴 — 가독성이 뛰어남
fonts-noto-cjk 구글 🌏 한중일 통합 — 범용성이 뛰어남
💡 폰트 설치 후 fc-cache -fv를 실행하면 시스템이 새 폰트를 바로 인식해요!
5

Fcitx 한글 입력기 설치하기

키보드로 한글을 타이핑할 수 있게 해줘요

Fcitx는 "한글 타자기"라고 생각하면 돼요. 이걸 설치해야 키보드에서 한글을 입력할 수 있어요!

터미널
# Fcitx 한글 입력기 설치
$ sudo apt install -y fcitx-hangul

# 기본 입력기를 Fcitx로 변경
$ im-config -n fcitx
🔧

im-config가 뭐예요?

im-config는 "Input Method Configuration"의 줄임말이에요. 쉽게 말해 "어떤 타자기를 쓸지 정해주는 설정 도구"예요. -n fcitx는 "Fcitx를 기본 타자기로 써!"라는 뜻이에요.

6

환경변수 설정하기

모든 프로그램에서 Fcitx가 작동하도록 설정해요

환경변수(Environment Variable)란 "컴퓨터 전체에 붙이는 메모"예요. 이 메모를 통해 모든 프로그램이 "아, Fcitx를 써야 하는구나!"라고 알 수 있어요.

⚠️
중요한 차이점!
~/.bashrc → 터미널에서만 적용됨
~/.xsessionrc → 모든 GUI 프로그램에서 적용됨 ✅
터미널 — ~/.xsessionrc에 환경변수 추가
# ~/.xsessionrc 파일에 환경변수 추가
$ cat << 'EOF' >> ~/.xsessionrc
export GTK_IM_MODULE=fcitx
export QT_IM_MODULE=fcitx
export XMODIFIERS=@im=fcitx
EOF
환경변수 역할 쉬운 설명
GTK_IM_MODULE GTK 앱의 입력기 지정 🌐 Firefox, 파일 관리자 등에서 한글 입력
QT_IM_MODULE Qt 앱의 입력기 지정 📝 VS Code, KDE 앱 등에서 한글 입력
XMODIFIERS X Window 입력기 지정 🖥️ 리눅스 데스크탑 전체에서 한글 입력

📄 완성된 ~/.xsessionrc 파일 내용

export GTK_IM_MODULE=fcitx
export QT_IM_MODULE=fcitx
export XMODIFIERS=@im=fcitx
7

재부팅하기

모든 설정을 적용하기 위해 컴퓨터를 다시 시작해요

지금까지 한 모든 설정은 컴퓨터를 다시 켜야 적용돼요. 마치 게임에서 설정을 바꾸면 "재시작"해야 적용되는 것과 같아요!

터미널
$ sudo reboot
⚠️ 재부팅 전에 열려 있는 파일은 꼭 저장해주세요!
8

설치 확인 & Fcitx 설정

모든 것이 제대로 되었는지 확인하고 한글 입력을 설정해요

재부팅이 완료되면 아래 순서대로 확인해보세요!

✅ 확인 1: 로케일 확인

터미널
$ locale

# 아래처럼 나오면 성공! 🎉
LANG=ko_KR.UTF-8

✅ 확인 2: Fcitx 상태 확인

터미널
# Fcitx가 실행 중인지 확인
$ fcitx -d

# Fcitx 설정 도구 열기
$ fcitx-configtool

✅ 확인 3: Fcitx 설정에서 한글 추가

📌
Fcitx 설정 방법:
1. fcitx-configtool 실행
2. 하단의 + 버튼 클릭
3. "Only Show Current Language" 체크 해제
4. 검색창에 "Hangul" 입력
5. Hangul 선택 후 OK
6. Ctrl + Space 또는 한/영 키로 한영 전환!

✅ 확인 4: 한글 입력 테스트

텍스트 편집기나 브라우저를 열고 한글을 입력해보세요!

테스트
# 터미널에서 한글 입력 테스트
$ echo "안녕하세요! 한글이 잘 보이나요? 🎉"

🔧 문제가 생겼을 때

😰 증상 1: Fcitx 설정에서 Hangul이 안 보여요

fcitx-hangul 패키지가 제대로 설치되지 않았을 수 있어요.

해결: sudo apt install --reinstall fcitx-hangul 후 재부팅

😰 증상 2: 브라우저에서만 한글 입력이 안 돼요

~/.xsessionrc 환경변수가 누락되었을 수 있어요.

해결: 6단계의 환경변수 3개가 ~/.xsessionrc에 모두 있는지 확인하세요. ~/.bashrc에만 넣으면 터미널에서만 적용되고 GUI 앱에는 적용되지 않아요!

😰 증상 3: 한글은 입력되는데 깨져 보여요 (□□□)

한글 폰트가 설치되지 않았을 가능성이 높아요.

해결: sudo apt install fonts-nanum fonts-noto-cjk 후 fc-cache -fv 실행

😰 증상 4: Fcitx 아이콘이 트레이에 안 나타나요

Fcitx가 자동 시작되지 않고 있을 수 있어요.

해결: ~/.xsessionrc 맨 끝에 fcitx-autostart &를 추가하거나, 시작 프로그램(Startup Applications)에 fcitx를 등록하세요.

⚡ 빠른 참조 (Quick Reference)

경험이 있는 사용자를 위한 명령어 요약이에요. 순서대로 터미널에 입력하세요!

① 패키지 업데이트 sudo apt update
② 언어팩 설치 sudo apt install -y language-pack-ko
③ 로케일 생성 sudo locale-gen ko_KR.UTF-8
④ 기본 언어 설정 sudo update-locale LANG=ko_KR.UTF-8
⑤ 폰트 설치 sudo apt install -y fonts-nanum fonts-noto-cjk
⑥ Fcitx 설치 sudo apt install -y fcitx-hangul
⑦ 기본 입력기 변경 im-config -n fcitx
⑧ 환경변수 (GTK) export GTK_IM_MODULE=fcitx
⑨ 환경변수 (Qt) export QT_IM_MODULE=fcitx
⑩ 환경변수 (X) export XMODIFIERS=@im=fcitx
⑪ 재부팅 sudo reboot
💡 ⑧~⑩ 환경변수는 ~/.xsessionrc 파일에 넣어야 GUI 앱에서도 적용돼요!
